# My Quarter 🌿

Your personal 90-day goal planner.

## Deploy to Vercel (5 minutes)

### 1. Upload to GitHub
- Go to [github.com](https://github.com) → Create free account
- Click **+** → **New repository** → name it `my-quarter` → Create
- Click **"uploading an existing file"** and drag the entire project folder in
- Click **Commit changes**

### 2. Deploy on Vercel
- Go to [vercel.com](https://vercel.com) → Sign in with GitHub
- Click **Add New Project** → select `my-quarter`
- Click **Deploy** (Vercel detects Vite automatically)

### 3. Done! 🎉
Your app is live at `https://my-quarter.vercel.app`

---

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Tech stack
- React 18 + Vite
- All data stored in localStorage (no backend needed)
- Fonts embedded directly – no external dependencies
